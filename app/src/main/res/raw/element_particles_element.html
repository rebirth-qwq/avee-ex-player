粒子

显示粒子场

粒子将以 2D 或 3D 方式运动，具体取决于“透视深度”属性

属性

通用元素属性

请参阅 常规属性

颜色

粒子的基础颜色，颜色也受 颜色起始 和 过渡到 影响

数量限制

任何给定时间可存在的最大粒子数量

X轴镜像

水平镜像所有粒子

Y轴镜像

垂直镜像所有粒子

透视深度

如果设大于 0，粒子将以 3D 方式运动，此值指定 3D 区域的深度。如果设为 0 或以下，粒子将以 2D 方式运动，无深度移动

透视视场角

指定视场角。用于 3D 粒子

生成区域

指定粒子出现的区域

水平线
垂直

如果设置，作为垂直线

使用随机向量

如果设置，粒子将以随机方向生成。此属性覆盖 向量角度

向量角度

指定粒子生成时的角度方向（度）

向量角度 Z

指定粒子生成时的 Z 轴方向。此值与 向量角度 结合创建 3D 向量。用于 3D 粒子

矩形
相对中心的向量

如果设置，粒子将从中心向外生成。对 2D 粒子有用。此属性覆盖 使用随机向量 和 向量角度

使用随机向量

如果设置，粒子将以随机方向生成。此属性覆盖 向量角度

向量角度

指定粒子生成时的角度方向（度）

向量角度 Z

指定粒子生成时的 Z 轴方向。此值与 向量角度 结合创建 3D 向量。用于 3D 粒子

力场

影响粒子运动的力场

自定义图像

用于粒子的图像

粒子缩放

粒子的基础缩放。缩放也受 起始尺寸、淡入尺寸、结束尺寸、随机结束尺寸 影响

拖尾长度

根据粒子速度拉伸粒子。用于模拟运动模糊

颜色起始

粒子生成时，颜色在 颜色起始 和 过渡到 之间随机混合

过渡到

粒子生成时，颜色在 颜色起始 和 过渡到 之间随机混合

淡入淡出时间

起始淡入和淡出结束阶段之间的时间。粒子尺寸变化分为三个阶段：起始尺寸 → 淡入尺寸 → 结束尺寸

速度角度

如果设置，粒子将根据其移动方向自动对齐

尺寸宽高比

设为 1.0 为方形粒子，其他值可制作宽粒子

起始尺寸

粒子生成时的尺寸

淡入尺寸

粒子在淡入阶段的尺寸。发生在 淡入淡出时间 指定的时间之后

结束尺寸

粒子生命周期结束时的尺寸

随机结束尺寸

为尺寸值添加随机分量。此值添加到 起始尺寸、淡入尺寸 和 结束尺寸

结束尺寸 Z 因子

根据粒子深度影响粒子尺寸
这是绝对属性，已无明确用途，3D 粒子请改用 透视深度 和 透视视场角

近相机淡出距离

当粒子靠近相机时在特定距离淡出。用于 3D 粒子

生成时间

每生成一个新粒子的间隔时间。值越低生成的粒子越多

测量整体速度

粒子速度的变量分量。总速度由以下组合定义：测量整体速度 + 速度 + 随机速度

速度

粒子的速度。总速度由以下组合定义：测量整体速度 + 速度 + 随机速度

随机速度

粒子的随机速度分量。总速度由以下组合定义：测量整体速度 + 速度 + 随机速度

生命周期

粒子生成后存在的总时间

重力

定义影响粒子运动的重力

侧边正弦波频率

波浪运动的速度/频率

随机侧边正弦波频率

波浪运动的随机速度/频率分量

侧边正弦波幅度

波浪运动的幅度

如果设置了幅度，粒子将向两侧来回移动/摆动

随机侧边正弦波幅度

波浪运动的随机幅度分量

如果设置了幅度，粒子将向两侧来回移动/摆动
